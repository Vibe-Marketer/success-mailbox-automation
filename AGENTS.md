# Project routing

- Read `README.md` for setup and safety rules.
- Read `01_prepare/CONTEXT.md` before preparing a batch.
- Read `02_approve/CONTEXT.md` before approving a batch.
- Read `03_connect/CONTEXT.md` before any live connection.
- Read `04_verify/CONTEXT.md` before verification.
- Never commit `.env`, input CSV files, normalized batches, approvals, progress, or reports.
- Never log tokens, OAuth codes, mailbox passwords, or full request bodies.
- Never retry a mailbox connection automatically after an ambiguous response.
- Never make the Success.ai API base configurable.
